``qaic`` package
==================

The ``qaic`` package provides a way to run inference on Qualcomm Cloud AI 100 accelerators.

Description
-----------

A user can create a session object by passing in one of the following:

1. A ``.onnx`` file.

2. A precompiled Qualcomm program container (QPC) as ``model_path``. The full path to qpc.bin should be passed while using the
   precompiled binary.


Run an inference example
^^^^^^^^^^^^^^^^^^^^^^^^^^

Option 1 : Compiles the ``onnx`` file to generate a QPC and sets up a session
for inference.

::

    import qaic
    import numpy as np
    sess = qaic.Session('/path/to/model/model.onnx') 
    input_dict = {'input_name': input_data}
    output = sess.run(input_dict)

Option 2 : Uses precompiled QPC and sets up a session for inference.

::

    import qaic
    import numpy as np
    sess = qaic.Session('/path/to/model/qpc.bin') # option 2 : Session uses compiled QPC file to 
    input_dict = {'input_name': input_data}
    output = sess.run(input_dict)

Example for benchmarking
^^^^^^^^^^^^^^^^^^^^^^^^^^^

::

    import qaic
    sess = qaic.Session(model_path='/path/to/model', backend='aic', options_path = '/path/to/yaml') # model_path can be either onnx or precompiled qpc
    inf_completed, inf_rate, inf_time, batch_size = sess.run_benchmark()

Limitations
-----------

-  Only supports QAic backend. 
-  APIs only support x86-64 platforms.

Class ``Session``
-------------------

``Session`` is the entry point for these APIs. It's a factory method
which you must call to create an instance of session. A model is
compiled by default when creating a session.

::

    Session(model_path, **kwargs)

Returns
^^^^^^^^

Session object based on the provided qpc.

Examples
^^^^^^^^

Using ``options_path`` YAML file:

::

    sess = qaic.Session('/path/to/model', options_path = '/path/to/options.yaml') 
    input_dict = {'input_name': input_data}
    output = sess.run(input_dict)

Example contents of YAML file:

::

    aic_num_cores: 4
    num_activations: 1
    convert_to_fp16: true
    onnx_define_symbol:
      batch: 1
    output_dir: './resnet_qpc'

Using keyword arguments:

::

        sess = qaic.Session('/path/to/model_qpc/*.bin', num_activations=4, set_size=10)
        input_dict = {'input_name': input_data}
        output = sess.run(input_dict)

API list (function variables for session object)
-----------------------------------------------------

Session class has following methods.

``backend_options()``
^^^^^^^^^^^^^^^^^^^^^

Returns
""""""""

A dict of options that can be configured after creating session.

Example
""""""""
::

    backend_options_dict = session.backend_options()

``get_metrics()``
^^^^^^^^^^^^^^^^^

Returns
""""""""

A dictionary containing the following metrics:

::

    - num_of_inferences (int): The number of inferences.
    - min_latency (float): The minimum inference time.
    - max_latency (float): The maximum inference time.
    - P25 (float): The 25th percentile latency.
    - P50 (float): The 50th percentile latency (median).
    - P75 (float): The 75th percentile latency.
    - P90 (float): The 90th percentile latency.
    - P99 (float): The 99th percentile latency.
    - P999 (float): The 99.9th percentile latency.
    - total_inference_time (float): The sum of individual inference times.
    - avg_latency (float): The average latency.

Example
""""""""

::

    metrics_dict = session.get_metrics()

``model_input_shape_dict()``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Returns
""""""""

A dict with ``input_name`` as key and ``input_shape``, ``input_type`` as values.

Example
""""""""""

::

    input_shape_dict = session.model_input_shape_dict() 

``model_output_shape_dict()``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Returns
""""""""

A dict with ``output_name`` as key and ``output_shape``, ``output_type`` as
values.

Example
""""""""""

::

    output_shape_dict = session.model_output_shape_dict()

``print_profile_data``
^^^^^^^^^^^^^^^^^^^^^^^^

Returns
""""""""

``None``

Example
""""""""""

::

    session.print_profile_data(n)   

Print profiling data for the first n iterations.

.. note::

   This function only works when 'enable_profiling' is set to True for the
   Session.

-  This method assumes that the 'enable_profiling' attribute is set to
   True, and the 'profiling_results' attribute contains the profiling
   data for each iteration.
-  The method prints the profiling data in a tabular format, including
   the file, line, function, number of calls, function time (seconds),
   and total time (seconds) for each function.

Sample Output:

::

    |  File-Line-Function  | |  num calls  | |  func time  | |  tot time  |

    ('~', 0, "<method 'astype' of 'numpy.ndarray' objects>") 1 0.000149101 0.000149101

    ('~', 0, '<built-in method numpy.empty>') 1 2.38e-06 2.38e-06

    ('~', 0, '<built-in method numpy.frombuffer>') 1 4.22e-06 4.22e-06

``reset()``
^^^^^^^^^^^

Returns
""""""""

``None``

Example
""""""""""

::

    session.reset() 

Releases all the device resources acquired by session.

``setup()``
^^^^^^^^^^^^^

Loads the network to the device. The network is usually loaded during first call of run. If this is called
before that, network will be already loaded when first run is called.

Returns
""""""""

``None``

Example
""""""""""

::

    session.setup() 

``run(input_dict)``
^^^^^^^^^^^^^^^^^^^^

Returns
""""""""

A dict with output_name and output_value of inference.

Example
""""""""""

::

    output = session.run(input_dict)    

input_dict should have input_name as key and value should be a numpy
array

``run_benchmark()``
^^^^^^^^^^^^^^^^^^^^

This API accepts the following arguments:

* ``num_inferences``: Number of inferences to run in benchmarking. Default ``40``.

* ``inf_time``: Duration for which inference is to be run in seconds. Default ``None``.

* ``input_dict``: Input to be used in inference. Default random.

.. note:: 
   :class: info 

   ``num_inferences`` and time can't be used together.

This API uses C++ benchmarking APIs and doesn't take into account Python overheads.

Returns
""""""""

* ``inf_completed``: Total number of inferences run.
  
* ``inf_rate``: Inf/sec of the model.
  
* ``inf_time``: Total time taken to run inferences 
 
* ``batch_size``: Batch size used by the model.

Example
""""""""""

::

    inf_completed, inf_rate, inf_time, batch_size = session.run_benchmark() 

``update_backend_options``\(\*\*kwargs)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The update options are specified in kwargs. For example, ``num_activation``, ``dev_id``, and ``set_size`` can be configured with this
API.

Returns
""""""""

``None``

Example
""""""""""

::

    session.update_backend_options(num_activations = 2)

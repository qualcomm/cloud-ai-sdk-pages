=============
Download SDKs
=============

The Platform SDK and Apps SDK are available from `Qualcomm Software Center <https://softwarecenter.qualcomm.com/>`__.

**What You Need**

- Platform SDK: Drivers, firmware, and runtime libraries
- Apps SDK: Compilation tools and development libraries

Other download options
----------------------

To browse all available versions and packages, open the SDK pages in Qualcomm Software Center:

* `Platform SDK <https://softwarecenter.qualcomm.com/catalog/item/aic_platform>`__
* `Apps SDK <https://softwarecenter.qualcomm.com/catalog/item/aic_apps>`__

SDK package contents
--------------------

**Platform SDK**

Filename format: ``aic_platform.Core.<version>.Linux-AnyCPU.zip``

Example: ``aic_platform.Core.1.23.2.0.Linux-AnyCPU.zip``

.. code-block:: text

   ├── x86_64/
   │   ├── deb/          # Debian packages for x86-64
   │   └── rpm/          # RPM packages for x86-64
   └── common/           # Shared test data and tools

**Apps SDK**

Filename format: ``aic_apps.Core.<version>.Linux-AnyCPU.zip``

Example: ``aic_apps.Core.1.23.2.0.Linux-AnyCPU.zip``

.. code-block:: text

   ├── x86_64/
   │   ├── deb/          # Debian packages for x86-64
   │   └── rpm/          # RPM packages for x86-64
   └── common/           # Examples, integrations, and tools
